# 项目中文说明

本项目研究 CNN 能否从 OHLCV 价格图像中学习具有经济意义的短期形态，并在横截面选股、组合排序及风险调整后产生可检验的收益预测能力。

## 核心流程

1. 获取并清洗中国 A 股日频行情，剔除北交所股票及上市不足 12 个月的股票。
2. 将 5、20、60 个交易日的 OHLCV 历史转换成图像矩阵，并构造未来 5 日涨跌二分类标签。
3. 针对三个窗口分别训练 CNN；每个窗口重复训练 5 次，并对预测概率做集成。
4. 按周进行横截面排序和十组组合回测，同时计算 IC、交易成本、等权/市值加权表现及因子回归结果。
5. 检验 20 日、60 日表示向 5 日任务的迁移效果。
6. 将 A 股训练模型应用到标准化美股数据，进行跨市场和迁移学习检验。

## 脚本分组

- `01`–`08`：A 股数据、图像、训练、预测与基础评估。
- `09`–`11`：A 股跨窗口迁移学习。
- `12`–`18`：美股数据标准化、图像、预测与基础评估。
- `19`–`22`：美股跨窗口迁移与评估。

## GitHub 中未包含的内容

原始数据、清洗后数据、`.npy` 图像张量、模型权重、预测结果、Excel 表格和图片均由脚本生成或体积较大，因此通过 `.gitignore` 排除。仓库保留完整最终代码、依赖说明和复现顺序。
